# Статус проекта InternetRadio

Модуль проигрывания интернет-радио на C# (netstandard2.0, без внешних зависимостей,
без привязки к Unity).

## Что реализовано и работает

### 1. Декодер MP3 (`Mp3Decoder`)
Собственный скалярный порт public-domain алгоритма [minimp3](https://github.com/lieff/minimp3) (CC0).
Поддерживается MPEG-1/2/2.5 **Layer III**: моно, стерео, Joint Stereo (M/S + intensity),
короткие блоки, битовый резервуар.

**Валидация:**
- побитово идентичен эталонному minimp3 (собран оригинальный C через tcc, `max diff = 0`);
- на 146-секундном музыкальном MP3 320 кбит/с: корреляция **0.99999999997** с ffmpeg,
  макс. расхождение **2 LSB**, отношение сигнал/ошибка **−102.7 дБ**, длина выборки
  совпадает (кадры не терялись и не дублировались);
- чистый синус декодируется с THD ≈ −95 дБ.

### 2. Стриминг (`StreamClient`, `IcySplitter`)
- сырой TCP (+TLS через SslStream), ручной разбор статус-строки `ICY 200 OK` /
  `HTTP/1.0 200 OK` и заголовков;
- разбор in-band ICY-метаданных (`StreamTitle`, UTF-8);
- **HTTP-редиректы (302)** — до 10 переходов;
- автопереподключение при обрыве.

### 3. Буферизация
- `RingBuffer` — потокобезопасный кольцевой буфер (по умолчанию 1 МБ);
- пребуфер перед стартом декодирования (по умолчанию 128 КБ ≈ 8 с аудио);
- `WaveOutPlayer` — 24 блока ~100 мс ≈ 2.4 с между декодером и звуковым устройством.

### 4. Публичный API (`InternetRadio`)
`SetUrl` / `Start` / `Stop` + события `PcmDecoded` (PCM 16 бит, interleaved),
`StreamTitleChanged`, `StateChanged`, `Error`. Кроссплатформенный, без Unity-зависимостей.

### 5. Тестовый плеер (`tests/InternetRadio.Tests`)
- `decode <mp3> <pcm>` — офлайн-декодирование файла;
- `chunk <mp3> <pcm> <размер>` — декодирование файла порциями заданного размера
  (регресс-тест потокового пути декодера: результат обязан совпадать с `decode`);
- `live <url> <сек> <wav>` — запись потока в WAV;
- `play <url> <сек>` — живое проигрывание на Windows (waveOut/winmm) + диагностика;
- `wavplay <file.wav> [сек]` — проигрывание локального WAV тем же плеером (изоляция
  уровня воспроизведения от сети/декодера; логирует позицию устройства `waveOutGetPosition`
  и дрейф позиции относительно настенных часов).

Проверено на станциях: `http://195.91.237.50:8000/ices128` и
`http://myradio24.org/ussr` (обе — MP3 128 кбит/с, 44.1 кГц, Joint Stereo M/S).

## Сборка и проверка

```powershell
dotnet build InternetRadio.sln -c Release

# живое проигрывание (Windows):
dotnet run --project tests\InternetRadio.Tests -c Release -- play http://myradio24.org/ussr 30

# запись в WAV:
dotnet run --project tests\InternetRadio.Tests -c Release -- live http://myradio24.org/ussr 15 out.wav
```
